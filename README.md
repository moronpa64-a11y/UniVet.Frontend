# Uniremington al Parque - Frontend 🐾

¡Bienvenido al repositorio del Frontend de **Uniremington al Parque**! Esta es una aplicación web SPA (Single Page Application) diseñada para la gestión, control y seguimiento de las jornadas de salud veterinaria y proyección social universitaria.

La interfaz permite administrar de forma eficiente los roles de usuarios (Administradores, Docentes, Estudiantes), el registro de beneficiarios, historias clínicas veterinarias, eventos y noticias.

## 🚀 Tecnologías Utilizadas

* **Angular (v17+)** - Framework principal para la arquitectura del proyecto.
* **Angular Material** - Componentes de diseño y UI (Tablas, Formularios, Cards, Diálogos).
* **RxJS** - Manejo de flujos de datos asíncronos y reactividad.
* **TypeScript** - Lenguaje de programación tipado para lógica robusta.
* **SCSS** - Hojas de estilo modulares y avanzadas.

## 🛠️ Requisitos Previos

Antes de iniciar, asegúrate de tener instalado:
* [Node.js](https://nodejs.org/) (Versión LTS recomendada)
* [Angular CLI](https://angular.io/cli) (`npm install -g @angular/cli`)
